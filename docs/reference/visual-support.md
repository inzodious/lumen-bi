# Visual support reference

> **Applies to:** Creators · Analysts · Developers

This reference lists every visual type Lumen knows: the types it renders, the ones it shows as a placeholder, and what each supports. Use it to check whether a report built in Power BI Desktop will render in Lumen, or which visual to pick.

> [!NOTE]
> This page is generated by `scripts/docs/gen-visual-support.mjs` from the visual registry (`src/renderer/src/visuals/registry.ts`) and the Visualizations pane catalog (`src/renderer/src/panes/visualizations/catalog.ts`). Run `node scripts/docs/gen-visual-support.mjs` to refresh it. The **Status** column and its notes are **assessed by hand** from the renderers' code and comments; everything else is read from code.

## Status values

| Status | Meaning |
|---|---|
| Native | Lumen has its own renderer that aims to match Power BI Desktop's look and behaviour. Small differences are listed in the visual's article. |
| Approximate | The visual renders and is interactive, but part of it works differently by design (no map tiles, statistics instead of Microsoft's AI models, no cloud service). The visual says so where it matters. |
| Placeholder | The type is offered in the Visualizations pane so field wells can be edited and the file round-trips, but the canvas shows a hatched box that reads "This visual type isn't supported yet". |
| Unsupported | Any other type, including AppSource and organizational custom visuals not listed here: the canvas shows a hatched box that reads "This custom visual isn't supported in Lumen" (custom visuals) or "This visual type isn't supported yet". The visual's JSON is kept as it is when you save. |

## Notes by visual

| Visual | Status | Notes |
|---|---|---|
| Clustered column chart | Native | Analytics lines, error bars, small multiples, zoom slider. |
| Stacked column chart | Native | Total labels; analytics lines, error bars, small multiples. |
| Clustered bar chart | Native | Analytics lines, error bars, small multiples. |
| Stacked bar chart | Native | PBIR type of the stacked bar chart. See the duplicate gallery tile below. |
| Line chart | Native | Forecast and Find anomalies are approximations of Power BI's algorithms. |
| Area chart | Native | Find anomalies is an approximation. |
| Ribbon chart | Native | No Analytics tab (as in Power BI). |
| Pie chart | Native | Small multiples supported. |
| Donut chart | Native | Small multiples supported. |
| Gauge | Native | Maximum is extended when the target exceeds the default maximum (approximation of Power BI's rule). |
| KPI | Native | No cross-highlight. |
| Waterfall chart | Native | No Analytics tab. |
| Scatter chart | Native | Play axis animates frames; bubble size scaling is an approximation. |
| Map | Approximate | No map tiles: vector country / US-state outlines; offline geocoding of countries, states, regions, about 21,000 cities and places, and US ZIP3 centroids. |
| Filled map | Approximate | Fills countries, US states and continents only; no tiles. |
| Shape map | Approximate | Built-in geometry only (US states or world countries); custom TopoJSON maps are not read. |
| Azure map | Approximate | Bubble layer only, drawn on the same vector basemap as the Map visual; no tiles. |
| Decomposition tree | Approximate | AI splits (High value / Low value) are offered for every measure; Power BI hides them for complex measures. |
| Key influencers | Approximate | Per-field significance tests, not Power BI's regression model; the visual says so. |
| Narrative | Approximate | Template sentences over the page's data; no Copilot or language model. |
| Q&A | Approximate | Small rule-based grammar instead of the Power BI Q&A service; fails on some models. |
| Table | Native | Data windowing of 500 rows; sparklines render but cannot be added in Lumen. |
| Matrix | Native | Data windowing of 500 rows; expand / collapse and drill on rows and columns. |
| Card | Native | Some default sizes and spacings are measured from screenshots (approximation). |
| Slicer | Native | All styles of the classic slicer, including date picker and relative date / time. |
| List slicer | Native | Supports hierarchies (several Field levels) with expand / collapse. |
| Button slicer | Native | Some orientation / overflow encodings are undocumented (approximation). |
| Text box | Native | Text boxes are inserted from the ribbon, not from the gallery. |
| Shape | Native | Inserted from Insert > Shapes. |
| Image | Native | Inserted from Insert > Image or Insert > Icon. |
| Button | Native | Inserted from Insert > Buttons. |
| Page navigator | Native | Inserted from Insert > Buttons > Page navigator. |
| Bookmark navigator | Native | Rendered when a report contains one; Lumen has no command to insert it. |
| HTML Content | Native | Re-implementation of the AppSource HTML Content visual; HTML is sanitized. |
| Deneb | Native | Renders Vega and Vega-Lite specifications with the Vega library; no Deneb editor (edit the JSON in the Format pane). |
| Power Automate for Power BI | Approximate | The button renders as formatted; flows cannot run outside the Power BI service. |
| Code visual | Native | Lumen only: HTML templates, CSS and JSX in a sandbox, cross-filtering and drill-down like a native visual. Power BI Desktop cannot display it (designed to show its "can't display this visual" placeholder; not verified). Highlighted when it has Rows; filtered like a card with measures only. |
| Stacked bar chart (`stackedBarChart`) | Placeholder | Defect: a first "Stacked bar chart" gallery tile inserts this unregistered type. Use the second tile (barChart). |
| R script visual (`scriptVisual`) | Placeholder | R script visuals do not run. |
| Python visual (`pythonVisual`) | Placeholder | Python visuals do not run. |
| Metrics (`scorecard`) | Placeholder | Metrics (scorecard) needs the Power BI service. |
| Paginated report (`paginatedReport`) | Placeholder | Paginated report visuals need the Power BI service. |

## Capabilities

- **In gallery**: the visual has a tile in the Visualizations pane gallery.
- **Highlight**: the visual can be cross-highlighted by a selection in another visual (otherwise it is cross-filtered).
- **Drill**: the visual supports drill down / up on hierarchical wells.
- **Data**: the visual provides its data to **Show as table** and **Export data**.
- **Analytics**: the Visualizations pane shows the **Analytics** tab (reference lines and more) for the visual.
